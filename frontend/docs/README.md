# 📸 Evidencias de Diseño y Capturas de Figma · Help Chair

Este directorio está destinado a almacenar las capturas de pantalla, prototipos exportados y evidencias visuales de los diseños elaborados en **Figma** para cada módulo del frontend.

## 📁 Estructura por Prácticas y Módulos

```text
frontend/docs/
├── access/       # Capturas y evidencias del módulo de Accesos (Equipo 2)
├── dashboard/    # Capturas del Dashboard central / Home
├── events/       # Capturas del Monitor de Gestión de Eventos (Equipo 1)
├── incidents/    # Capturas de la Gestión de Incidencias (Equipo 4)
├── knowledge/    # Capturas de la Base de Conocimiento (Equipo 5)
├── problems/     # Capturas de la Gestión de Problemas (Equipo 5)
├── public/       # Capturas del Portal Público / Landing / Registro de Empresas
└── requests/     # Capturas de la Gestión de Peticiones (Equipo 3)
```

## ⚠️ Reglas para Subir Archivos

1. **Solo evidencias visuales y documentación:**
   - Este directorio es **exclusivo para imágenes (.png, .jpg, .webp, .svg) o documentos de soporte (.md)**.
   - **PROHIBIDO** alojar código fuente (`.tsx`, `.ts`), subproyectos de Vite o archivos `package.json` aquí.
2. **Convención de nombres:**
   - Usa nombres en **minúsculas** en formato kebab-case (ej. `dashboard-incidentes.png`, `modal-nuevo-ticket.png`).
   - **NO uses espacios, mayúsculas, tildes ni caracteres especiales** para evitar conflictos de codificación en sistemas Git, Linux y Windows.
